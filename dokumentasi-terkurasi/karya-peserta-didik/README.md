# Karya Peserta Didik

## Nusantara Lost Archive

`nusantara-lost-archive/` berisi empat screenshot terkurasi dari proyek PictoBlox: ruang arsip, identifikasi motif, learning card, dan quiz room. Tangkapan layar dikonversi ke WebP berkualitas tinggi tanpa metadata EXIF dan ditampilkan pada studi kasus di `portfolio-1.html`.

File proyek `.sb3` dan dua PDF penjelas tetap berada pada folder sumber/Google Drive; file asli tidak disalin ke repositori publik. Pastikan izin publikasi dan pengaturan akses folder dikonfirmasi sebelum situs dipublikasikan.
