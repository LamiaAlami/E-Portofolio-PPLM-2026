# Dokumentasi Terkurasi

Folder ini disediakan untuk **salinan dokumentasi pilihan** yang sudah diperiksa dan memang akan ditampilkan pada portofolio.

Folder sumber `Dokumentasi/` di root proyek sengaja diabaikan oleh Git. Jangan memindahkan seluruh arsip mentah ke folder ini. Pilih hanya foto atau klip yang relevan, edit/kompres seperlunya, lalu pastikan izin publikasi dan privasi peserta didik sudah diperiksa.

## Struktur

- `foto/kelas/` — foto pilihan kegiatan pembelajaran di kelas.
- `foto/non-mengajar/` — kegiatan sekolah di luar pembelajaran kelas.
- `video/pembelajaran/` — video implementasi pembelajaran pertemuan/siklus.
- `video/kokurikuler/` — video kegiatan kokurikuler Malang Heritage.
- `karya-peserta-didik/` — contoh proyek atau karya yang sudah mendapat izin untuk ditampilkan.

Gunakan nama file deskriptif, misalnya `02-kompilasi-siklus-1.mp4` atau `05-kompilasi-siklus-4.mp4`. Hindari nama lengkap peserta didik, nomor induk, nilai, atau informasi akun pada nama file maupun isi media.

Video kompilasi yang sudah dipasang pada halaman portofolio berada di `video/pembelajaran/` dan `video/kokurikuler/`. Media baru tetap tidak otomatis ditampilkan di situs; tambahkan tautan dan keterangan yang sesuai setelah pemeriksaan privasi.
